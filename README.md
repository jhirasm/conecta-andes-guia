# Conecta Andes: guía legal del comercio electrónico

Aplicación web interactiva que explica, en lenguaje simple, cómo un grupo de cuatro empresas peruanas puede pasar al comercio electrónico cumpliendo la **Ley N.° 29733** y su nuevo Reglamento (**D.S. N.° 016-2024-JUS**).

Basada en el *Informe Jurídico N.° 002-2026* del Seminario de Derecho y Nuevas Tecnologías, Facultad de Derecho, Universidad Católica San Pablo (UCSP), semestre 2026-2.

## ¿Para quién es?
Para personas que **no conocen de derecho** y quieren entender el tema.

## Contenido
| Pestaña | Qué ofrece |
|---|---|
| Inicio | Resumen del caso y glosario |
| Ruta | 5 pasos para migrar al comercio electrónico, con progreso |
| Empresas | Ficha de Conecta Estilo, AgroConecta Perú, Conecta Ediciones y Conecta Crédito MYPE |
| Datos | Herramienta: "¿necesito consentimiento?", derechos ARCO, incidentes y transferencia internacional |
| Cookies | Simulador del banner de cookies por empresa |
| Delitos | Delitos informáticos (Ley 30096), penas y prevención |
| Quiz | 5 preguntas de repaso |

## Cómo ejecutarla
No necesita instalación ni dependencias. Abre `index.html` en el navegador, o con un servidor local:

```bash
python -m http.server 8000
# luego visita http://localhost:8000
```

## Publicación en GitHub Pages
1. Sube el repositorio a GitHub.
2. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. La app quedará en `https://TU-USUARIO.github.io/conecta-andes-guia/`.
